# WebCatalog: Каталог мікроконтролерів

Навчальний проєкт із дисципліни «Веб-технології».

## Тема
Каталог мікроконтролерів: містить характеристики популярних моделей
і потрібен для швидкого порівняння та вибору під задачу.

## Модель даних
Поля одного запису:
- `name` — модель
- `bits` — розрядність
- `frequency` — частота, МГц
- `interfaces` — інтерфейси
- `voltage` — живлення, В
- `family` — родина
